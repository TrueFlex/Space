# Space

Учебный репозиторий для упражнений по Git к лабораторной работе 5 по информатике (ГУАП).

Каждая ветвь хранит файлы своего формата:

| Ветвь | Что лежит | Формат |
| --- | --- | --- |
| `main` | программа на Python, которая считает дни до сдачи заданий | код (`.py`) |
| `ВтораяВетвь` | конспекты лабораторных работ из Obsidian | текст (`.md`) |
| `ТретьяВетвь` | схемы из презентации об ИИ-агентах | графика (`.png`) |

Ветвь `ВтораяВетвь` объединена с `main` через pull request.

Индивидуальный проект работы – лендинг «Учебный планировщик студента»: [TrueFlex/study-planner](https://github.com/TrueFlex/study-planner).
